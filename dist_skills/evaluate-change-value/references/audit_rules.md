# 审计规则

## 阻塞项

出现以下情况，不能输出强结论：

- 缺少变更前或变更后量价渠表。
- 缺少销量、收入、成本、毛利中的任一关键字段。
- 未定义目标区域或目标变更关键词，且输入中存在多区域/多 SKU 混合。
- 前后表字段口径无法映射。
- 结论声称由本次变更导致，但归因表未标记为 `directly_related` 或 `portfolio_related`。

## 警告项

出现以下情况，最多输出 `条件认可`，并必须写风险：

- 总毛利额增长但综合毛利率下降。
- 新增低价 SKU 带来增量，同时高配或顶配毛利下降。
- 竞品价格只有单点信息，缺少销量或促销节奏。
- 用户价值仅由配置推断，缺少直接 VOC 或用户研究支撑。
- 渠道收入增长但渠道毛利率下降。

## 证据覆盖

每个关键结论至少需要一个证据来源：

- 用户价值：DOCX/调研/VOC/明确用户场景。
- 竞争价值：竞品价格、规格、价差或替代关系。
- 财务价值：前后销量、收入、毛利、ASP、成本。
- 组合风险：SKU 级或渠道级前后变化。
- 执行风险：供应链、库存、售后、渠道费用或明确缺失项。

## 公式检查

- 毛利率 = 毛利额 / 渠道销售收入。
- 加权 ASP = `sum(ASP * 渠道销量) / sum(渠道销量)`。
- 加权目标成本 = `sum(目标成本 * 渠道销量) / sum(渠道销量)`。
- 新增 SKU 贡献 = 新增 SKU 指标 / 总盘增量。
- 大于 100% 的结果不能写成转化率，只能写成贡献倍率或贡献占比异常，并解释分母较小或抵消项。
