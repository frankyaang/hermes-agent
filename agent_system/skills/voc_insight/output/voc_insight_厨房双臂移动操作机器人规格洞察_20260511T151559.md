## 0. 结论先行

**核心洞察**：厨房机器人真正的用户购买理由不是“有几自由度”，而是：**能否在有热、有水、有油、有刀具、有儿童/宠物干扰的厨房里，稳定、安全、卫生地完成一组明确菜谱和收尾清洁，且不额外制造维护负担。**

因此，产品规格建议不要从“全屋通用人形厨师”起步，而应从**受控厨房工作站 + 双臂协作 + 标准化厨具/容器 + 可验证动作库**切入：

1. **双臂是必要项**：开盖、扶锅、倒料、搅拌、装盘、拿取重物等任务天然需要一手固定、一手操作；单臂移动平台更适合取放/递送，不足以承担完整烹饪闭环。
2. **7 DoF/臂是合理主流规格**：Franka、Kinova、YuMi、TIAGo 等研究/协作平台均围绕 7 DoF 形成“类人绕障 + 狭窄空间操作”能力。厨房台面空间狭小，6 DoF 可做基础动作，7 DoF 更利于避让锅柄、柜门、龙头和人体。
3. **载荷目标应分层**：MVP 建议每臂连续有效载荷 **2–3 kg**，双臂协同搬运 **5–8 kg**；但第一代不要承诺“自由举起任意满锅”，应通过锅具滑轨、夹持治具、双臂协同和安全姿态限制降低风险。
4. **清洁与食品安全是成败门槛**：IP 等级、食品级接触材料、可拆洗末端、油污防护、交叉污染控制，优先级不低于算法。
5. **动作库比泛化大模型更接近产品化**：应先定义 30–50 个可测量原子动作与 20–50 个可交付菜谱，而非承诺任意食材/任意厨房/任意菜式。
6. **首代形态建议“固定/轨道式厨房机器人”优先于“全屋移动厨师”**：Moley 的集成厨房路线与 Mobile ALOHA 的研究演示共同说明：移动操作有价值，但产品化瓶颈在环境标准化、失败恢复和安全认证。

本次未获得真实用户评论/VOC 数据，以下洞察基于公开技术资料与研究/商业样机的规格对比。关键参考如下：

| 类别 | 参考对象 | 公开规格摘录 | 对厨房机器人的启示 |
|---|---:|---|---|
| 高灵敏协作臂 | **Franka Research 3** | 7 DoF；载荷 3 kg； reach 855 mm；重复定位 <±0.1 mm；7 个集成扭矩传感器 | 7 DoF + 关节力矩感知是厨房接触任务的高价值组合；适合搅拌、插入、擦拭、轻碰撞检测 |
| 轻量研究臂 | **Kinova Gen3 7DoF** | 7 DoF；最大 reach 902 mm；中程连续载荷 4 kg、满伸连续载荷 1.1 kg；IP33；扭矩/位置/速度/电流等传感 | 标称载荷要按“姿态/伸展距离”降额；厨房不能只看峰值载荷，必须定义工作姿态下连续载荷 |
| 双臂协作平台 | **ABB YuMi IRB 14000** | 双臂，每臂 7 轴；载荷 0.5 kg/臂；reach 0.559 m；重复定位 ±0.02 mm；碰撞检测、软包覆 | 双臂精细装配路线证明“双臂+安全包覆+小载荷”可协作，但厨房搬锅/倒料需更高载荷 |
| 工业双臂 | **Yaskawa Motoman SDA10F** | 15 轴双臂；载荷 10 kg；水平 reach 1970 mm；垂直 reach 1440 mm | 工业双臂证明大载荷/大工作域可实现，但体积、成本、安全包覆、清洗适配不适合直接家用 |
| 家庭移动操作 | **Hello Robot Stretch 3** | 2 kg payload；24.5 kg；33×34×141 cm；2–5 h 续航；7 total DOF（含移动底盘/升降/伸缩/腕）；RGBD + 激光 | 家庭移动平台适合“到达真实家庭位置”，但单臂/低载荷限制其完成完整厨房烹饪 |
| 研究型移动操作 | **PAL Robotics TIAGo** | 110–145 cm；臂载荷 3 kg；7 DoF arms；可选双臂、6 轴 F/T、端执行器；4–5 h/8–10 h 续航 | 移动 + 升降躯干 + 7DoF 臂是服务机器人常见结构，厨房需额外解决食品安全和湿热油污 |
| 双臂移动模仿学习 | **Mobile ALOHA** | 面向低成本全身遥操作/模仿学习；演示煎/盛虾、开双门柜放锅、冲洗锅等厨房任务 | 研究验证了“厨房任务需要双臂 + 全身移动 + 数据采集”，但产品仍需强约束动作库与可靠恢复 |
| 集成厨房商业化 | **Moley Robotic Kitchen** | 两个机械臂与全关节“手”；智能冰箱、灶具、机器人友好厨具；光学系统、UV 灯、菜谱库、三轴轨道 | 商业厨房机器人倾向“改造环境 + 标准厨具 + 菜谱库”，而不是直接适配任意家庭厨房 |

## 2. 用户需求翻译：用户实际关心什么

### 2.1 用户不直接购买技术指标，而购买五个“确定性”

| 用户语言 | 技术语言 | 产品验收口径 |
|---|---|---|
| “别把厨房弄得更麻烦” | 清洁维护复杂度、可拆洗、油污防护 | 单次烹饪后人工清洁 ≤5 分钟；关键食品接触件可拆洗/洗碗机清洗 |
| “别烫到人、别打翻锅” | 安全速度、力控、热区识别、双臂搬运稳定 | 热锅/刀具动作必须有安全锁、视觉确认、力/扭矩限幅和紧急停止 |
| “能做我常吃的菜，不要只会演示” | 菜谱覆盖、动作库、失败恢复 | 首发菜谱 ≥20 道高频菜；每道菜成功率、平均人工介入次数可量化 |
| “我家厨房不想大改” | 安装边界、台面适配、厨具兼容 | 提供标准工作站版本；明确最小台面宽深高、水电气/电磁炉/排烟条件 |
| “食材形态变化大也能处理” | 视觉分割、柔顺抓取、容器/治具标准化 | 首代用标准容器/预切食材降低变量；非结构化食材逐步扩展 |

### 2.2 “厨房机器人”的真实高风险不是单点动作，而是闭环

厨房动作链条通常是：识别食材 → 抓取 → 移动 → 处理 → 加热 → 调味 → 装盘 → 清洁。任何一步失败都会让用户觉得“不可信”。所以规格设计要从**任务闭环可靠性**倒推，而不是单独堆叠机械臂参数。

## 3. 产品规格建议

### 3.1 整机形态建议

**首代优先形态：固定/轨道式双臂厨房工作站**

- **推荐结构**：台面/橱柜集成的上方或后方轨道 + 双 7DoF 机械臂 + 可升降/横移机构 + 顶视/腕部视觉。
- **不建议首代承诺**：自由移动到任意厨房位置、打开任意冰箱/橱柜、使用任意锅具和刀具、做任意菜式。
- **原因**：移动底盘引入导航、地面障碍、家庭成员干扰、锅具热液搬运等安全复杂度；首代应把变量锁在工作站内。

**第二阶段形态：移动底盘作为“取放/递送/收纳”模块**

- 移动模块可负责从冰箱/餐桌/洗碗机取放标准容器，但高温烹饪、刀具、热锅操作仍留在固定工作站内。

### 3.2 自由度与运动系统

| 模块 | 建议规格 | 理由 |
|---|---|---|
| 机械臂 | **2 × 7 DoF** | 狭窄厨房需要冗余自由度绕障；双臂协同是锅盖、锅柄、倒料、夹持、开柜的基础 |
| 轨道/躯干 | 1–3 DoF（横移/升降/前后） | 用低风险线性自由度扩大工作域，减少机械臂极限姿态工作 |
| 头部/视觉云台 | 2 DoF 可选 | 改善遮挡、锅内观察、用户交互 |
| 移动底盘 | 第二阶段可选，差速/全向均可 | 不作为首代烹饪核心路径，避免安全和认证难度过高 |
| 系统总 DoF | 固定工作站约 17–20 DoF；移动版约 20+ DoF | 包含双臂、轨道/升降、头部/底盘等；重点是可控工作域而非炫技 |

### 3.3 臂长、载荷、精度

| 指标 | 建议值 | 说明 |
|---|---:|---|
| 单臂有效 reach | **800–900 mm** | 覆盖 600 mm 常见台面深度 + 锅/砧板/水槽局部区域；参考 Franka 855 mm、Kinova 902 mm |
| 单臂连续载荷 | **2–3 kg** | 覆盖盘子、碗、锅铲、小锅、食材盒；满伸状态需降额 |
| 单臂峰值/短时载荷 | 4–5 kg | 用于短时搬移，不作为持续搅拌/悬停承诺 |
| 双臂协同载荷 | **5–8 kg** | 覆盖较重锅具/食材容器，但需限定姿态、速度和路径 |
| 重复定位 | 机械端 ≤1 mm；食品任务允许 2–5 mm | 精密装配级 ±0.02 mm 非必要；关键是视觉闭环 + 力控 |
| 末端速度 | 正常 ≤0.5 m/s；近人/热液/刀具更低 | 按安全区域动态限速；高速不是厨房首要价值 |
| 防护等级 | 臂体建议 IP54+；腕部/末端接触件 IP65/IP67 | 油、水、蒸汽、洗涤剂环境要求高于普通研究臂；Kinova IP33 类研究臂不能直接厨房产品化 |

### 3.4 末端执行器建议

**不要只做“仿人五指手”。首代更建议“快换工具族 + 少量柔性抓手”。**

| 工具族 | 必备能力 | 规格建议 |
|---|---|---|
| 食品级柔性夹爪 | 抓蔬菜、包装、碗盘、锅柄 | 食品级硅胶接触面；可拆洗；最大开口 ≥90–120 mm；具备防滑纹理与力反馈 |
| 平行夹爪/刚性夹具 | 抓标准容器、锅柄、刀柄/铲柄 | 夹持力可控；热隔离；可识别工具 ID；过载释放 |
| 吸附/负压工具 | 抓盖子、盘子、包装袋等平面/半平面物 | 防液体倒吸；可快速清洗；真空状态监测 |
| 烹饪工具接口 | 铲、勺、夹、搅拌棒、刮刀 | 统一快换接口；RFID/视觉标识；工具误装检测 |
| 清洁工具 | 擦拭、刮油、冲洗辅助 | 与食品接触工具隔离；一次性/可洗耗材；避免交叉污染 |

**关键建议**：末端快换要比“更像人手”更重要。厨房任务大多可以通过机器人友好厨具降低难度，例如固定锅柄、标准碗盘、带识别标记的调料盒和防滑容器。

### 3.5 视觉与力控

| 子系统 | 建议配置 | 核心用途 |
|---|---|---|
| 顶视 RGB-D | 1–2 个固定相机，覆盖台面/锅/水槽 | 全局定位、食材/容器识别、遮挡检测 |
| 腕部 RGB/RGB-D | 每臂 1 个，带防污透明罩 | 近距离抓取、锅内观察、手眼闭环 |
| 头部/侧视相机 | 可选 | 与用户交互、补充遮挡视角 |
| 力/扭矩 | 关节力矩 + 腕部 6 轴 F/T 或等效估计 | 搅拌、刮擦、插入、盖合、碰撞检测 |
| 触觉/指尖压力 | 在柔性夹爪上配置 | 防滑落、防夹碎、识别软硬食材 |
| 热感知 | 热区/锅具温度检测，热像或红外点温可选 | 热锅、热油、蒸汽风险控制 |

**算法建议**：使用“视觉定位 + 力控验证 + 动作后检查”的闭环。厨房里视觉会被蒸汽、油污、遮挡影响，不能只依赖一次性视觉识别。

## 4. 安全、清洁与兼容性要求

### 4.1 安全红线

1. **刀具开放操作不进首代全自动核心路径**：切菜可通过预切食材、封闭切割模块或人工前处理实现；若引入刀具，必须是封闭治具。
2. **热锅/热油/热液搬运必须降级**：优先“锅不离灶/少移动”，通过倒料器、滑轨、固定锅柄、双臂低速协作完成。
3. **儿童/宠物/手伸入检测**：台面工作区需有视觉/红外/力矩多重检测；靠近即暂停或降速。
4. **紧急停止与物理隔离**：E-stop、软件暂停、工作区灯光提示、危险动作前语音/屏幕确认。
5. **权限分级**：高风险动作（加热、刀具、热液、玻璃）需要用户确认或被工作站封闭。

### 4.2 清洁设计

| 项目 | 建议规格 |
|---|---|
| 食品接触件 | 食品级材料；可拆卸；洗碗机可洗；不同食材/清洁工具颜色区分 |
| 臂体外观 | 无深缝、少螺丝外露、抗油污涂层；可湿布擦拭 |
| 腕部/相机 | 防油透明罩可快拆；雾气/油污检测提醒 |
| 工具仓 | 食品工具与清洁工具分仓；UV/热风/臭氧等消杀需符合地区法规 |
| 清洁 SLA | 单次烹饪后人工维护 ≤5 分钟；每周深度清洁 ≤20 分钟 |
| 交叉污染 | 生熟分离工具/托盘；过敏源/肉类/海鲜任务后强制清洁流程 |

### 4.3 食材与厨具兼容边界

**首代应明确“兼容清单”，不要让用户以为可处理任意厨房物品。**

| 兼容对象 | 首代建议 | 暂缓/限制 |
|---|---|---|
| 食材 | 预切蔬菜、块状肉类、鸡蛋、米面、调料包、标准容器装液体 | 活体/带壳海鲜、强粘连面团、超软易碎食材、非标准包装 |
| 锅具 | 标准锅柄/锅盖、带视觉标记或几何特征、重量受控 | 任意老旧锅具、过重铸铁锅、无隔热把手锅 |
| 餐具 | 标准盘/碗/杯，尺寸、重量、材质定义 | 超薄玻璃、异形餐具、湿滑堆叠餐具 |
| 厨电 | 电磁炉、蒸烤箱、智能水槽/龙头，接口开放 | 明火燃气炉首代谨慎；任意传统旋钮/机械开关需适配模块 |
| 环境 | 标准工作站、固定台面、明确水电/排风条件 | 任意家庭厨房自由部署 |

## 5. 动作库建议

### 5.1 原子动作库（MVP 必备）

| 动作类别 | 原子动作 | 验收指标示例 |
|---|---|---|
| 识别定位 | 识别食材/容器/锅具/工具、姿态估计、空位检测 | 目标识别准确率、定位误差、遮挡报警率 |
| 抓取取放 | 单臂抓取、双臂协同托举、容器取放、工具快换 | 成功率、滑落率、夹碎率、平均重试次数 |
| 开合操作 | 开盖、合盖、开抽屉/柜门、开包装辅助 | 力控稳定性、夹手/碰撞次数 |
| 倒入转移 | 倒水、倒料、撒调料、从容器入锅 | 溢洒量、目标量误差、残留率 |
| 烹饪动作 | 搅拌、翻炒、刮锅、翻面、夹取、舀取 | 温度/时间/力度一致性，食物完整度 |
| 装盘 | 夹取、舀取、摆盘、擦边 | 装盘成功率、污染/洒落率 |
| 清洁收尾 | 擦台、刮油、冲洗锅具/工具、废料转移 | 可见残留、清洁耗时、人工介入 |
| 失败恢复 | 重试、请求用户、回安全位、暂停加热 | 可解释失败率、危险停机成功率 |

### 5.2 菜谱库策略

- **首发菜谱**：20–50 道高频、步骤稳定、食材形态可控的菜谱。
- **菜谱 DSL**：每道菜由“原子动作 + 感知检查点 + 安全条件 + 失败恢复”组成，而不是只存自然语言步骤。
- **上线门槛**：每道菜定义成功率、平均人工介入次数、清洁耗时、食材浪费率。
- **渐进扩展**：先“加热/搅拌/倒料/装盘”，后“复杂切配/高温油炸/开放式煎炒”。

## 6. 产品路线建议

### Phase 0：验证样机（3–6 个月）

- 双 7DoF 臂 + 固定台面 + 顶视/腕部视觉 + 快换工具。
- 验证 10 个核心动作：抓取、倒料、搅拌、开盖、装盘、擦拭等。
- 不追求外观家电化，目标是动作成功率和安全边界。

### Phase 1：厨房工作站 MVP（6–12 个月）

- 20 道标准菜谱；标准锅具/容器/调料盒；封闭或半封闭工作区。
- 支持用户语音/屏幕选择菜谱、确认高风险动作、处理异常。
- 交付指标：单菜成功率 ≥90%（受控食材/厨具下），人工介入 ≤1 次/菜，烹饪后人工清洁 ≤5 分钟。

### Phase 2：移动辅助模块（12–24 个月）

- 移动底盘用于取放标准容器、送餐、收纳；烹饪核心仍在工作站。
- 引入冰箱/洗碗机/餐桌协同，但不把高温热液搬运作为首要卖点。

### Phase 3：更开放厨房泛化

- 扩展更多厨具、食材和家庭厨房布局；引入更强的视觉语言模型/模仿学习。
- 必须建立大规模真实厨房失败数据闭环，而不是只依赖演示视频。

## 7. Top 用户洞察与产品化建议

| 排名 | 洞察结论 | 对产品规格的直接建议 |
|---:|---|---|
| 1 | 用户最怕“不安全/不卫生/不可靠”，不是怕功能少 | 安全与清洁作为 P0 规格，不晚于机械臂选型 |
| 2 | 双臂是厨房任务闭环的刚需 | 单臂移动平台可做外围，不适合作为完整烹饪主方案 |
| 3 | 任意厨房适配会吞噬产品化周期 | 先做标准工作站和机器人友好厨具 |
| 4 | 末端执行器决定可做菜谱范围 | 建立快换工具生态，而不是押注单一五指手 |
| 5 | 力控/触觉比亚毫米精度更贴近厨房 | 优先关节力矩、腕部 F/T、指尖压力和柔顺控制 |
| 6 | 食材不确定性高，需要标准容器与预处理 | 首代支持预切/标准包装食材，逐步扩展非结构化食材 |
| 7 | 清洁维护若超过省下时间，用户会放弃 | 设定清洁 SLA 和可拆洗设计指标 |
| 8 | 高温、刀具、玻璃是信任杀手 | 高风险动作做封闭治具、确认机制和保守降级 |
| 9 | 菜谱体验需要可解释失败 | 每个动作有检查点、失败原因和用户接管方式 |
| 10 | 演示视频成功 ≠ 产品可靠 | 用“每道菜成功率/介入次数/清洁耗时/安全停机”作为核心 KPI |

## 8. 建议规格清单（可进入 MRD/PRD）

### 必选规格（P0）

- 双臂：2 × 7 DoF，单臂 reach 800–900 mm。
- 载荷：单臂连续 2–3 kg，双臂协同 5–8 kg（限定姿态/速度）。
- 感知：顶视 RGB-D + 双腕部相机；热区检测；工具/容器识别。
- 力控：关节力矩感知 + 腕部 6 轴 F/T 或等效方案；指尖压力/触觉。
- 末端：食品级柔性夹爪、刚性夹具、吸附工具、烹饪工具快换接口。
- 安全：E-stop、近人降速、手伸入暂停、热/刀具动作确认、碰撞检测。
- 清洁：食品接触件可拆洗；臂体可擦拭；工具分仓；交叉污染流程。
- 动作库：至少 30 个原子动作；20 道标准菜谱；动作级失败恢复。

### 体验规格（P1）

- 菜谱选择、进度可视化、异常解释、用户确认、语音/屏幕双交互。
- 自动生成购物/备料清单；与标准食材盒/调料盒配套。
- 烹饪后清洁提示与耗材寿命提醒。

### 暂不建议首代承诺（P2/后续）

- 任意厨房自由移动烹饪。
- 开放刀具切配全自动。
- 任意锅具/餐具/食材兼容。
- 高温油炸、明火燃气炉自主操作。
- 完全无需用户介入的全自动“机器人厨师”。

## 9. 风险提醒

1. **过度泛化风险**：若产品口径是“任意厨房任意菜”，技术、认证、售后都会失控。
2. **卫生认证风险**：研究臂常见 IP 等级和外壳结构不满足厨房油水蒸汽环境，不能直接商品化。
3. **载荷误读风险**：很多机械臂标称载荷不是满伸、长时间、带工具、带热液状态下的有效载荷；PRD 必须定义姿态和工况。
4. **末端复杂度风险**：仿人手自由度高但清洁、耐油、耐热、维护成本高；快换专用工具更现实。
5. **失败恢复风险**：厨房中“小失败”会演变为洒落、糊锅、烫伤和清洁灾难，动作库必须内置恢复策略。

---

## 10. 可复用的产品定义一句话

> **建议把首代厨房机器人定义为“受控厨房工作站内的双臂烹饪与清洁助手”，而不是“能在任意家庭厨房独立行动的人形厨师”。**  
> 产品规格应围绕“安全、卫生、稳定、可维护、菜谱可验证”建立，而机械臂自由度、载荷、视觉算法都应服务于这些用户确定性。
