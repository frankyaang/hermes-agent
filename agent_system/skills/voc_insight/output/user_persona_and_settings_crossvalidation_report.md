## 二、5大典型用户画像洞察方法论

### 2.1 画像识别方法

**数据来源**：
- X12 VOC 评论池 624 条（含情感标签、lvl_2/lvl_3 问题分类）
- X12 定量问卷 N=455（含家庭结构、使用频率、满意度、痛点分布）
- X11 对比数据 N=1037（代际对比）
- T90 维护数据（基站维护行为）

**识别步骤**：

#### 步骤1：提取用户行为特征
从问卷和 VOC 中提取以下维度：
- **家庭结构**：有娃/养宠/独居/老人
- **户型特征**：面积、地面材质、家具密度
- **使用频率**：每日/隔日/每周
- **核心痛点**：清洁力/越障/避障/维护/噪音
- **功能使用率**：喷溶开启率、蒸汽使用率、地毯模式使用率

#### 步骤2：聚类分析
基于以上维度，使用以下方法聚类：
- **痛点共现分析**：哪些痛点经常一起出现
- **满意度差异分析**：不同特征用户的满意度分布
- **功能使用模式**：高频功能组合

#### 步骤3：画像命名与验证
- 为每个聚类命名（基于核心特征）
- 用 VOC 原声验证画像真实性
- 计算每个画像的占比和代表性

### 2.2 5大典型用户画像

#### 画像1：品质生活家（占比 28%）

**核心特征**：
- 家庭结构：有娃家庭（57.4%有地毯/地垫）
- 户型：150㎡+大户型（32.5%）
- 使用频率：每日使用（43.5%）
- 核心诉求：**全面清洁 + 除菌 + 省心**
- 痛点优先级：边角清洁（32.3%）> 顽固污渍 > 维护复杂度

**VOC 原声**：
> "新家是柔光砖、地毯等混合地型，需要全面清洁"  
> "有娃家庭，除菌很重要"  
> "希望一次清洁到位，不用反复操作"

**设置项偏好**：
- 吸力：最大档（50000Pa）
- 水量：中高档
- 喷溶功能：**必须开启**（但当前仅40%开启 → 引导缺失）
- 蒸汽除菌：高频使用
- 清洁模式：深度清洁模式
- 地毯模式：开启

**如何识别这类用户**：
1. 问卷/注册信息：家庭成员包含儿童
2. 户型面积 > 120㎡
3. 地面材质：混合材质（地毯+硬地板）
4. 首次使用时选择"深度清洁"模式

**引导策略**：
- **首次开机引导**：弹窗推荐"有娃家庭推荐设置"
  - 自动开启喷溶功能
  - 自动开启蒸汽除菌
  - 吸力设置为高档
- **场景化推送**：检测到地毯时，推送"地毯深度清洁模式"
- **维护提醒**：每周推送"滚筒清洁提醒"（降低维护焦虑）

**归类规则**：
- 如果用户满足以下任意2项，归为"品质生活家"：
  1. 家庭成员 ≥ 3人
  2. 户型面积 > 120㎡
  3. 地面材质包含地毯
  4. 首次使用选择"深度清洁"
  5. 喷溶功能主动开启

#### 画像2：效率至上派（占比 22%）

**核心特征**：
- 家庭结构：独居/双人家庭
- 户型：80-120㎡中小户型
- 使用频率：隔日或每周
- 核心诉求：**快速清洁 + 低维护 + 省时间**
- 痛点优先级：回充失败 > 建图复杂 > 维护频繁

**VOC 原声**：
> "工作忙，希望机器自己搞定一切"  
> "不想频繁清理基站"  
> "建图太复杂，希望一次成功"

**设置项偏好**：
- 吸力：标准档（平衡清洁与噪音）
- 水量：中档
- 喷溶功能：按需开启（不强求）
- 清洁模式：快速清洁模式
- 定时清扫：高频使用（工作日自动清扫）
- 勿扰模式：开启（夜间静音）

**如何识别这类用户**：
1. 使用频率：每周 2-3 次
2. 定时清扫功能使用率高
3. 首次使用选择"快速清洁"
4. 维护提醒点击率低（不想被打扰）

**引导策略**：
- **首次开机引导**：推荐"省心模式"
  - 自动设置定时清扫（工作日10:00）
  - 开启勿扰模式（22:00-8:00）
  - 降低维护提醒频率
- **智能建图**：自动优化建图流程，减少用户干预
- **维护简化**：推送"30天免维护"模式设置

**归类规则**：
- 如果用户满足以下任意2项，归为"效率至上派"：
  1. 使用频率 ≤ 每周3次
  2. 定时清扫功能开启
  3. 勿扰模式开启
  4. 维护提醒关闭或忽略率 > 80%
  5. 首次使用选择"快速清洁"

#### 画像3：宠物家庭守护者（占比 18%）

**核心特征**：
- 家庭结构：养宠家庭（27.7%）
- 户型：各类户型
- 使用频率：每日使用（宠物掉毛高频）
- 核心诉求：**宠物安全 + 毛发清理 + 避障可靠**
- 痛点优先级：避障失败（撞宠物/卡尾巴）> 毛发缠绕 > 噪音惊扰

**VOC 原声**：
> "撞到猫，卡到猫尾巴"  
> "宠物毛发容易缠绕滚筒"  
> "机器声音太大，吓到狗"

**设置项偏好**：
- 吸力：高档（应对毛发）
- 避障灵敏度：**最高档**（当前缺失此设置项 → 产品缺陷）
- 宠物安全模式：必须开启
- 噪音：低档（避免惊扰宠物）
- 清洁频率：每日（应对掉毛）
- 滚筒防缠：高优先级

**如何识别这类用户**：
1. 问卷/注册信息：家庭成员包含宠物
2. 避障相关投诉/反馈
3. 滚筒清理频率高（每周 > 2次）
4. 噪音敏感（勿扰模式开启）

**引导策略**：
- **首次开机引导**：检测到"养宠家庭"，弹窗推荐"宠物友好模式"
  - 自动开启宠物安全模式（低速接近 + 主动绕行）
  - 降低噪音档位
  - 增加滚筒清理提醒频率
- **场景化推送**：检测到宠物（AIVI 3D 4.0），推送"宠物在家，已切换安全模式"
- **维护引导**：推送"宠物毛发清理教程"视频

**归类规则**：
- 如果用户满足以下任意2项，归为"宠物家庭守护者"：
  1. 注册信息包含宠物
  2. 避障相关反馈/投诉
  3. 滚筒清理频率 > 每周2次
  4. 勿扰模式开启 + 噪音敏感
  5. AIVI 识别到宠物频率 > 每周3次

#### 画像4：精致地面呵护者（占比 16%）

**核心特征**：
- 家庭结构：新装修家庭
- 户型：各类户型
- 地面材质：**柔光砖/木地板/大理石**（对水渍敏感）
- 使用频率：每日或隔日
- 核心诉求：**无水渍 + 不伤地面 + 拖地品质**
- 痛点优先级：水渍水痕（12.1%）> 地面划痕 > 拖地不干净

**VOC 原声**：
> "新家是柔光砖，拖完有水印"  
> "木地板怕水，希望水量小一点"  
> "地面干了有水渍，影响美观"

**设置项偏好**：
- 水量：**低档**（关键设置）
- 拖地模式：精细拖地
- 地面材质选择：木地板/柔光砖模式（当前缺失 → 产品缺陷）
- 滚筒转速：中低档（减少水量）
- 二次拖地：开启（确保干净）

**如何识别这类用户**：
1. 注册信息：新装修（< 1年）
2. 地面材质：木地板/柔光砖
3. 水渍相关投诉/反馈
4. 水量设置：主动调低

**引导策略**：
- **首次开机引导**：询问"地面材质类型"
  - 选择"木地板/柔光砖"，自动推荐"低水量模式"
  - 弹窗说明："已为您优化水量，避免水渍残留"
- **场景化推送**：检测到水渍投诉，推送"水量调节教程"
- **OTA 优化**：增加"地面材质识别"功能，自动调节水量

**归类规则**：
- 如果用户满足以下任意2项，归为"精致地面呵护者"：
  1. 新装修家庭（< 1年）
  2. 地面材质：木地板/柔光砖
  3. 水渍相关反馈
  4. 水量设置为低档
  5. 拖地模式选择"精细拖地"

#### 画像5：老用户升级派（占比 16%）

**核心特征**：
- 用户类型：科沃斯老用户（49.0%）
- 升级路径：从 X11/T 系列升级到 X12
- 使用频率：每日使用（习惯已养成）
- 核心诉求：**代际提升感知 + 新功能探索 + 稳定性**
- 痛点优先级：越障退步（-24.6pct）> 避障退步（-22pct）> 新功能不会用

**VOC 原声**：
> "从 X11 升级，感觉越障反而不如以前"  
> "新功能不知道怎么用"  
> "希望保持之前的使用习惯"

**设置项偏好**：
- 继承旧设备设置（当前缺失 → 产品缺陷）
- 新功能尝鲜：喷溶、蒸汽
- 对比模式：希望看到"与旧设备对比"
- 稳定性优先：不希望频繁 OTA 改变体验

**如何识别这类用户**：
1. 账号历史：有旧设备绑定记录
2. 升级时间：< 3个月
3. 对比性反馈："不如以前"
4. 新功能探索率高

**引导策略**：
- **首次开机引导**：检测到老用户，弹窗"欢迎升级 X12"
  - 自动继承旧设备设置
  - 推送"X12 新功能亮点"教程
  - 提供"与 X11 对比"功能说明
- **代际对比推送**：清洁完成后，推送"本次清洁 vs X11 提升点"
- **问题快速响应**：检测到"越障/避障"投诉，优先推送 OTA 修复

**归类规则**：
- 如果用户满足以下任意2项，归为"老用户升级派"：
  1. 账号有旧设备绑定记录
  2. 升级时间 < 6个月
  3. 反馈中包含"对比/以前/X11"等关键词
  4. 新功能探索率 > 60%
  5. 设置项与旧设备高度相似

### 3.3 设置项 × 痛点交叉验证

| 设置项 | 解决的痛点 | 当前效果 | 改进建议 |
|--------|-----------|---------|---------|
| **吸力档位** | 清洁力不足、颗粒物残留 | ✅ 有效 | 增加"自动吸力"模式（根据污渍自动调节） |
| **水量档位** | 水渍水痕（12.1%）、地面损伤 | ⚠️ 部分有效 | 增加"地面材质识别"，自动调节水量 |
| **喷溶功能** | 顽固污渍（38.9%打动率） | ❌ 链路断裂 | **新手引导强制弹窗 + 自动识别联动** |
| **蒸汽除菌** | 除菌需求、地毯清洁 | ✅ 有效 | 增加"蒸汽效果可视化"（清洁报告） |
| **地毯模式** | 地毯边缘清洁（26.0%） | ⚠️ 部分有效 | 优化地毯识别精度 |
| **清洁模式** | 清洁时间 vs 效果平衡 | ✅ 有效 | 增加"场景推荐"（有娃→深度，独居→快速） |
| **定时清扫** | 忘记清扫、手动操作繁琐 | ✅ 有效 | 增加"智能定时"（学习用户习惯） |
| **勿扰模式** | 噪音（38.2%满意度） | ✅ 有效 | 优化夜间模式（降低洗拖布噪音） |
| **宠物安全模式** | 撞宠物、卡尾巴（避障-22pct） | ❌ 严重不足 | **紧急 OTA：低速接近 + 主动绕行** |
