# Overseas After-sales Consultation Data Analysis Report

## Executive Summary

**Data Scale**: 40,377 overseas after-sales consultation records

**Key Findings**:

1. **Failure-related consultations dominate** (48.7%), the primary pressure point for overseas after-sales
2. **Australia and the US are the two largest consultation markets**, each accounting for 16%
3. **DEEBOT brand accounts for 54.3%**, T-series and N-series each account for 33%, the main consultation subjects
4. **After-sales service inquiries account for 14.3%**, reflecting user concerns about service processes and efficiency
5. **Usage guidance needs account for 9.5%**, indicating room for optimization in product onboarding and user education
