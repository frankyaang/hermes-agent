## 执行摘要

本报告基于 **40,375** 条海外售后咨询记录，覆盖 **32个国家/地区**、**462个机型**，分析了用户咨询的核心问题、区域分布特征和机型系列差异。

### 核心发现

1. **区域集中度高**：澳大利亚(16.01%)、美国(16.00%)、法国(13.80%)、德国(11.94%)、韩国(10.28%)五国占总咨询量的 **68.03%**

2. **故障类问题占主导**：所有地区和系列中，"故障(Failure)"类咨询均占 **40-58%**，是售后咨询的绝对主力

3. **TOP 3 高频问题**：
   - 充电问题 (Unable to charge/fully charge): 1,386条 (3.43%)
   - 污水回收故障 (Waste water cannot be recycled): 1,028条 (2.55%)
   - 导航模块故障 (DToF/LDS/Navigation module malfunction): 994条 (2.46%)

4. **系列差异**：
   - **X Series** (高端): 故障率56.23%，产品体验咨询占比4.46%（最高）
   - **T Series** (中端): 故障率55.83%，使用指导需求11.40%
   - **N Series** (入门): 故障率58.25%（最高），使用指导需求14.56%（最高）

## 六、战略行动建议

     - 质量侧: 排查充电触点、电池管理系统、基站充电模块

     - 服务侧: 提供污水系统清洁服务包

## 七、方法论说明

### 数据来源
- **数据源**: 飞书多维表格 - 海外售后咨询数据
- **数据时间**: 截至报告生成时间
- **数据规模**: 40,375 条有效记录

### 分析维度
1. **区域分布**: 32个国家/地区的咨询量分布
2. **品牌/品类/系列**: DEEBOT、YEEDI品牌及X/T/N系列分布
3. **问题分类**: 一级分类(Failure, How to use等) + 二级分类(具体问题)
4. **交叉分析**: 地区×问题、系列×问题

### 机型分类逻辑
- **品牌识别**: DEEBOT / YEEDI / 其他
- **系列识别**: 
  - X Series (X1, X2, X3, X5, X8, X10, X12) → High-end
  - T Series (T5, T8, T9, T10, T20, T30, T50, T90) → Mid-range
  - N Series (N7, N8, N9, N10, N20, N30, N79) → Entry-level

### 数据边界
- 部分记录机型字段为空或"Null-Ecovacs"，归类为"未知"
- 问题分类采用原始英文分类，部分二级分类未完全翻译
- 案例展示每个问题最多3个真实案例
