## 3. 设置项交叉验证结论

12 个核心设置项中，8 个已有、1 个部分实现、3 个缺失。运营上最关键的不是“设置项数量”，而是以下 4 条链路断裂：

1. **喷溶功能有功能但缺引导**：品质生活家是最大人群（28%），喷溶对顽固污渍有打动率，但开启率约 40%，应优先做首次引导、污渍识别联动和清洁报告可视化。
2. **宠物安全模式部分实现但体验不足**：宠物家庭守护者占 18%，避障满意度只有 55.4%，且有“撞宠物/卡尾巴”等高敏感场景，应进入 P0 OTA。
3. **地面材质选择缺失**：精致地面呵护者占 16%，当前只能调水量，无法表达木地板/柔光砖/瓷砖的策略差异，应新增地材选择或自动识别策略。
4. **越障策略缺失/稳定性需回查**：老用户升级派占 16%，越障较 X11 下降 24.6pct，应优先判断是算法阈值、传感器灵敏度还是场景识别策略问题。

## 5. 监测与例会看板建议

建议从下周开始建立四层看板：

1. **战略层**：平均满意度、高风险画像占比、NPS。
2. **画像层**：5 大画像占比、各画像满意度、画像迁移趋势。
3. **功能层**：喷溶、宠物安全、地面材质、定时、勿扰、避障灵敏度等设置项使用率。
4. **痛点层**：越障不稳定、避障失败、喷溶未开启、水渍水痕、回充失败、噪音不满。

预警规则：
- 平均满意度 < 65%：触发产品紧急复盘。
- 高风险画像占比 > 30%：触发用户关怀和专项修复。
- P0 设置项使用率 < 目标 50%：触发引导优化。
- 痛点投诉连续 4 周上升：触发产品缺陷分析。
- 新兴画像占比 > 5%：触发画像定义 workshop。
