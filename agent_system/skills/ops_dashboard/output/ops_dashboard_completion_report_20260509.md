## 💡 关键设计原则

### 1. 8字段标准格式
所有专项管理看板的统一规范，确保"一眼清晰"：
- 专项目标 / 本月重点 / 关键指标 / 当前进展
- 已产生价值 / 待关闭问题 / 需要协同资源 / 下阶段输出

### 2. 人员矩阵符号化
- ●主责 / ○协作 清晰标识分工
- 负荷评估原则 = 1主责 + 2-3协作为合理负荷

### 3. 问题闭环5状态流转
待讨论 → 讨论中 → 待决策 → 执行中 → 已完成

### 4. 统一汇报4原则
结论先行 / 数据说话 / 问题导向 / 简洁明了

### 5. 复盘4步法
回顾目标 → 评估结果 → 分析原因 → 总结经验

### 6. 一页总表风险等级
绿/黄/红 快速标识项目健康度，适合管理层快速决策
