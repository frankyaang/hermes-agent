## 1. 核心洞察与用户价值北极星

**一句话结论**：用户真正需要的不是“机器人会按洗衣机按钮”或“能折一件衣服”，而是从**散落脏衣 → 正确收集 → 安全投放洗烘 → 洗烘完成 → 干衣取出 → 可收纳折叠 / 叠放 → 指定区域交付**的少接管家务闭环。

### 建议北极星指标

> **有效无人值守洗叠闭环率**：在限定家庭环境、限定衣物品类和限定洗烘设备下，用户通过语音、App 或智能体发起任务后，机器人无需用户持续看管即可完成脏衣收集、投放、关门、正确启动洗烘、洗烘完成处理、取出、折叠 / 叠放和指定区域交付；过程中无误收、误洗、衣物损伤、设备异常和高危安全事件，最终结果被用户认可为可直接收纳。

### MVP 边界建议

- **首版 Must**：已验证兼容的前置式洗烘一体机、固定洗衣区、用户指定区域 / 脏衣篮、标准日常衣物、固定折叠平面、指定叠放位置、统一任务状态机。
- **首版不承诺**：所有洗衣机 / 烘干机、全屋任意散落衣物、所有衣物材质、精细分拣、独立洗衣机到烘干机转运、直接入柜收纳。
- **运营判断**：先把“少接管闭环”做扎实，再扩展设备、衣物品类和收纳深度。

| 设计需求 3 | 异常可接管，用户不需要从头排查。 |
| 设计指标 3 | 异常原因可解释率 ≥95%，用户接管路径一步可见。 |

| 外观设计参考建议 | 机身或基站保留简洁状态灯 / 小屏；颜色不宜过于玩具化，适合家务空间；洗衣区提示灯需在潮湿环境下清晰可见。 |
| 优先级 | P0 |

| 优先级 | P0 |

### 功能卡 5｜洗烘完成监控、取出与转运

| 字段 | 内容 |
|---|---|
| 用户价值 | 用户不用记洗完没、烘干没，也不用自己打开机器取出热 / 湿 / 皱的衣物。 |
| 核心功能名称 | 洗烘完成处理与干衣取出转运 |
| 功能描述 | 读取或判断洗烘完成状态，确认门锁解除、温度 / 湿度安全，开门取出干衣，检测滚筒残留并转运到固定折叠平面。 |
| 功能性质 | P0 闭环补全功能；没有该段，洗衣任务会停在“机器已启动”而不是“家务已完成”。 |
| 成本浮动空间建议 | **中低浮动**：完成状态、残留检测和潮湿判断不可砍；复杂防皱整理、精细散热策略可后置。 |
| 关键部件参考建议 | 设备状态接口、温湿度传感、视觉残留检测、柔性抓取末端、衣物承托托盘 / 转运篮、低速移动底盘。 |
| 材料性质需求 | 转运篮需防潮、透气、易清洗；接触热衣物部件需耐温；接触布料部件需低静电、防勾丝。 |
| 功能规格需求 | 完成状态识别后再开门；确认衣物干燥可折叠；取出后检查滚筒残留；未干、过热、门锁异常、设备报错时进入异常反馈。 |
| 智能化需求 | 洗烘状态读取 / 推断、湿度异常识别、滚筒残留视觉检测、转运路径规划、异常分级。 |
| 核心参数/关键指标 | 完成状态识别 ≥98%；滚筒残留率 ≤2%；掉落污染率 ≤1%；潮湿衣物误折叠 ≤2%；异常反馈 ≤30s。 |
| 用户体验验证标准 | 用户不需要自己去看洗完没；取出后无明显漏衣、掉地、潮湿误折叠；异常时知道是否等待、重烘或接管。 |
| 设计需求 1 | 洗完后任务自动进入下一段。 |

## 5. P0 / P1 / P2 行动建议

### P0｜立项和封闭试点前必须锁定

1. **锁定首版支持边界**：前置式洗烘一体机、固定洗衣区、标准衣物、指定区域、固定折叠平面。
2. **把调研问卷升级为兼容性闸门**：输出支持 / 不支持 / 灰名单 / 需校准，并形成机型支持库。
3. **建立端到端任务状态机**：从触发到折叠交付，每一步可见、可暂停、可接管、可追溯失败原因。
4. **拆解原有综合成功率**：开门、投放、关门锁止、程序选择、启动确认分别看，不只看 ≥90% 总数。
5. **建立误拾取 / 误洗 / 损伤红线**：非衣物误投放、门未锁启动、漏水、卡门、衣物损伤为一票否决事件。
6. **建立折叠质量评分**：按衣物类型、平整度、方向、堆叠稳定、可收纳评分定义 ≥90%。

### P1｜4–8 周家庭试点优化

1. 扩展从脏衣篮到卧室 / 沙发边等指定区域。
2. 做家庭成员、衣物品类、收纳点规则配置。
3. 优化智能体建议触发，重点看采纳率、取消率和低打扰反馈。
4. 建立失败原因库，按设备、衣物、区域、动作、算法分类复盘。
5. 增加洗涤剂 / 耗材 / 水路 / 门锁等状态提示。

### P2｜产品化扩展阶段

1. 扩展独立洗衣机 + 烘干机短距离转运。
2. 支持更多门型、面板、旋钮、触控和品牌 API。
3. 进入衣柜 / 抽屉深度收纳。
4. 增加复杂衣物折叠和精细洗护。
5. 与智能家居平台、洗衣机品牌、家庭日程联动。
