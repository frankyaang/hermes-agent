## 附录 — 授权操作指引

### 如何为张欢生成 OAuth 授权链接

```bash
# 步骤1：生成授权 URL（需张欢 open_id）
~/.hermes/scripts/feishu_user_oauth.py auth-url --name 张欢 --open-id <ou_...> --json

# 步骤2：张欢打开链接，完成授权，粘贴最终跳转 URL 或 code=... 值

# 步骤3：交换 token
~/.hermes/scripts/feishu_user_oauth.py exchange '<final-redirect-url-or-code>' --name 张欢 --open-id <ou_...>

# 步骤4：验证状态
~/.hermes/scripts/feishu_user_oauth.py status --person 张欢
```

> ⚠️ **注意**：不要向任何人索要或暴露 `user_access_token` / `refresh_token` 值。仅传递授权链接和最终重定向 URL。
