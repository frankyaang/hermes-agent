## 九、关键决策建议

### 决策1：是否立即启动宠物安全模式OTA？
**建议**: ✅ 立即启动  
**理由**: 影响18%用户，满意度仅55.4%，流失风险高，竞品已有类似功能  
**风险**: OTA升级需要3-4周，期间仍有投诉风险  
**缓解**: 同步上线APP端"宠物避让提示"功能作为过渡

### 决策2：地面材质选择功能是否值得投入？
**建议**: ✅ 值得投入  
**理由**: 影响16%用户，水渍投诉12.1%，功能开发成本低（纯APP端）  
**预期ROI**: 开发成本2周，满意度提升15.8%，NPS提升5-8分

### 决策3：是否需要新增"避障灵敏度"设置项？
**建议**: 🟡 暂缓至P2  
**理由**: 虽然影响18%用户，但宠物安全模式OTA可能解决80%问题  
**建议**: 先观察宠物OTA效果，若满意度仍< 65%再启动

### 决策4：画像系统是否需要在APP端显式展示？
**建议**: 🟡 内部使用，不对用户展示  
**理由**: 避免给用户贴标签的负面感知  
**替代方案**: 用"智能场景"替代画像概念，用户更易接受
