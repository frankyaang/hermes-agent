## 0. 核心问题回答

**用户的问题**: 理解阿基米德 Charter 文档 5.2 节「新考卷新场景」的逻辑与考卷原则，并基于已确认的 4 个核心卖点设计相应的新功能考卷。

**核心结论**:
1. **考卷是「验证层」，与「传播层」（明星场景）形成互补**。明星场景负责对外传播打透一个痛点，考卷负责对内拆解验证全场景覆盖。
2. **1:1:1 追溯结构**：每个核心卖点 → 对应一个明星场景 → 对应一张考卷。考卷将明星场景的「一句话传播」拆解为可量化验收的子场景矩阵。
3. **阿基米德应设计 4 张考卷**（对应 4 个核心卖点），其中 3 张与明星场景直接绑定，1 张（二合一水箱）作为底层支撑能力融入其他考卷。
4. **考卷设计采用「主场景 + 附加题」结构**：主场景覆盖核心卖点 80% 价值，附加题覆盖边缘场景和跨卖点协同。

## 4. 递归论证：为什么这样设计考卷

### 论证 1：为什么是 4 张考卷而不是 3 张？

用户最初设计的明星场景是 3 个（没有把二合一水箱单拎），但考卷必须覆盖**所有带差异化标签的核心卖点**。二合一水箱是 🔴 差异化（形态层面人无我有），如果缺少独立考卷，研发验证时会出现盲区：
- 水箱容量是否支撑 200㎡ 大户型？
- 超薄基站嵌入橱柜后的散热和噪音是否达标？
- 瞬时超充在大容量水箱下的实际表现？

**结论**：二合一水箱虽不作为传播抓手，但必须作为独立考卷验证其支撑能力。

### 论证 2：为什么「地毯SPA模式」考卷要区分「干蒸汽」和「湿蒸汽」？

地毯场景和厨房场景都用了变温蒸汽，但技术参数完全不同：
- **厨房（考卷#1）**：高温湿蒸汽，目标瓦解油膜，水渍残留是核心指标
- **地毯（考卷#4）**：低温/干态蒸汽，目标除螨除菌，**不能打湿地毯纤维**

如果在同一张考卷里验收，评审会追问「同一个技术怎么验收两次」。拆分后，每张考卷有独立的技术参数和验收逻辑。

### 论证 3：为什么附加题机制是必要的？

阿基米德的核心卖点是「全场景双效清洁」，但「全场景」无法在主场景里穷尽。附加题覆盖：
- **跨场景协同**：蒸喷系统在木地板上的除菌养护（非顽渍场景）
- **边缘场景**：地毯上的宠物尿液清洁（高痛点但低频）
- **竞品对标**：与竞品蒸汽功能的参数横评

附加题不做「必须赢」要求，但决定了产品是否能从「行业首个」变成「行业最好」。
