## 三、综合结论

### 3.1 MVP 一句话定义
> **2 代洗衣 / 叠衣机器人 MVP 应定义为：在已验证兼容的家庭环境中，机器人可通过语音、App 或智能体触发，在用户指定区域收集标准脏衣，安全投放至前置式洗烘一体机并启动预设洗烘程序，洗烘完成后取出干衣，在固定平面完成标准衣物折叠与叠放，并将结果交付到指定篮、台面或收纳点；全过程以统一状态机反馈，让用户无需持续看管。**

### 3.2 共同确认的产品边界

| 维度 | MVP 内应包含 | MVP 暂不包含 |
|---|---|---|
| 触发 | 语音 / App / 智能体建议或定时触发，统一任务状态机 | 三套入口各自独立、无状态同步 |
| 环境 | 售前问卷 + 首次实机校准，限定兼容家庭和固定洗衣区 | 默认支持所有家庭空间与所有设备布局 |
| 设备 | 前置式洗烘一体机、已验证门型 / 面板 / 程序 | 独立洗衣机 + 独立烘干机跨设备转运、全品牌全机型 |
| 衣物 | 标准日常混洗衣物、指定区域或脏衣篮来源 | 精细面料、复杂衣物、任意散落环境、口袋异物 100% 检出 |
| 洗烘链路 | 开门、投放、关门、锁门确认、正确程序启动、异常反馈 | 仅统计“放入滚筒并启动”的单一总成功率 |
| 洗后处理 | 完成状态识别、取出干衣、转运到固定折叠平面 | 洗完后仍要求用户取出 / 转运 |
| 折叠收纳 | 标准衣物折叠、叠放到指定篮 / 台面 / 收纳点 | 首版直接入柜、抽屉深度收纳、任意衣物全自动分类 |
| 智能化 | 家庭成员习惯建议触发、低打扰提醒、权限确认 | 成熟前直接强自动化、无确认地定时执行 |
| 安全红线 | 不误收非衣物、不误洗禁洗衣物、不夹衣、不漏水、不损伤衣物 | 用平均成功率掩盖红线事件 |

### 3.3 建议采用的验证指标

| 指标类别 | 建议门槛 / 方向 |
|---|---|
