## 三、综合结论

### 3.1 MVP 一句话定义
> **洗衣 / 叠衣机器人 MVP 应定义为：在已验证兼容的家庭环境中，机器人能够通过语音、App 或智能体触发，在用户指定区域收集标准脏衣，安全投放至前置式洗烘一体机并启动预设洗烘程序，洗烘完成后取出干衣，在固定平面完成标准衣物折叠与叠放，并以可解释状态反馈让用户无需持续看管。**

### 3.2 共同确认的产品边界

| 维度 | MVP 内应包含 | MVP 暂不包含 |
|---|---|---|
| 触发 | 语音 / App / 智能体建议或定时触发，统一任务状态机 | 三套入口各自独立、无状态同步 |
| 环境 | 售前问卷 + 首次实机校准，限定兼容家庭和固定洗衣区 | 默认支持所有家庭空间与所有设备布局 |
| 设备 | 前置式洗烘一体机、已验证门型 / 面板 / 程序 | 独立洗衣机 + 独立烘干机跨设备转运、全品牌全机型 |
| 衣物 | 标准日常混洗衣物、固定区域或脏衣篮来源 | 精细面料、复杂衣物、任意散落环境、口袋异物 100% 检出 |
| 洗烘链路 | 开门、投放、关门、锁门确认、正确程序启动、异常反馈 | 仅统计“放入滚筒并启动”的单一总成功率 |
| 洗后处理 | 完成状态识别、取出干衣、转运到固定折叠平面 | 洗完后仍要求用户取出 / 转运 |
| 折叠收纳 | 标准衣物折叠、叠放到指定篮 / 台面 / 收纳点 | 首版直接入柜、抽屉深度收纳、任意衣物全自动分类 |
| 安全红线 | 不误收非衣物、不误洗禁洗衣物、不夹衣、不漏水、不损伤衣物 | 用平均成功率掩盖红线事件 |

### 3.3 建议采用的验证指标

| 指标类别 | 建议门槛 / 方向 |
|---|---|
| 入口触发 | 语音唤醒率 ≥98%；意图识别准确率 ≥95%；端到端任务创建 ≤2s |
| 状态反馈 | 关键状态反馈 ≤3s；异常反馈 ≤30s；所有入口共享同一任务状态 |
| 设备兼容 | 问卷信息采集完整率 ≥95%；兼容判断准确率 ≥98%；首次校准通过后开放自动执行 |
| 收集 | 指定区域脏衣召回率 ≥90% 或限定品类 ≥95%；误拾取率 ≤2%；禁区进入 0 |
| 预检 | 大件 / 硬物等高风险异物提示召回率 ≥90%；特殊衣物进入待确认 |
| 投放启动 | 开门成功 ≥95%；投放成功 ≥90%；关门锁定确认 ≥98%；正确程序启动 ≥95% |
| 洗后处理 | 完成状态识别 ≥98%；滚筒残留 ≤2%；潮湿衣物误折叠 ≤2% |
| 折叠叠放 | 标准衣物折叠成功 ≥90%；堆叠稳定失败 ≤2%；用户可接受评分 ≥4/5 |
| 用户价值 | 单次任务非计划人工介入 ≤1 次；用户主动复用率提升；家务时间 / 走动 / 弯腰次数下降 |
| 安全红线 | 衣物损伤、漏水、卡门、误洗贵重衣物、误投放非衣物等高危事件目标为 0 |

### 3.4 运营优先级
1. **P0：锁定首版兼容环境** — 形成洗烘一体机机型、门型、控制方式、空间约束与首装校准支持矩阵。
2. **P0：建立端到端任务状态机** — 从触发到收集、投放、洗烘、取出、折叠、叠放每一步都有状态、失败原因与恢复动作。
3. **P0：定义衣物范围与禁洗规则** — 明确标准衣物、特殊衣物、口袋异物、非衣物、干净衣和禁区边界。
4. **P0：拆解原总成功率指标** — 把“投放-关门-启动 ≥90%”拆成开门、投放、关门、程序选择、启动确认等可诊断子指标。
5. **P0：建立红线事件审计** — 衣物损伤、误洗、漏水、夹衣、设备异常逐单复盘，一票否决。
6. **P1：扩展指定区域与分类规则** — 在脏衣篮 / 固定区域闭环稳定后，再做家庭成员、衣物品类、收纳点规则。
7. **P2：扩展全屋 / 全机型 / 深度收纳** — 仅在核心闭环稳定、失败原因库成熟后推进。
